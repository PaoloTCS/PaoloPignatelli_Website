SARAI — SenderAI–ReceiverAI Interface
Version 0.2 · March 2026

SARAI is a protocol for structured scientific communication between
AI-assisted researchers. It defines a three-object transmission bundle
that serves human and AI readers simultaneously.

A SARAI transmission consists of:
  1. A human letter — narrative, for the human recipient
  2. An AI Object — structured YAML, for the recipient's AI
  3. This protocol — defining the format both AIs use

SARAI objects are FIL Objects: instances of the Fundamental Interaction
Language framework made transmissible. Every SARAI object is simultaneously:
  · A communication between two humans
  · A communication between two AI systems
  · A node in an immutable provenance chain
  · A legal instrument establishing IP priority
  · A live parameter set for experimental platforms
  · A self-demonstrating proof of the theory it describes

The genesis transmission of SARAI v0.2 was sent to Anthropic Research
Leadership, March 2026.
